Paso 1 de 16

Paso 1 de 16 · Guía

Qué vamos a construir

Vas a organizar un proyecto web real a partir de los cuatro ejemplos de la guía de addEventListener(). En lugar de tener todo en un solo archivo, cada ejercicio tendrá su propia página HTML y su propio archivo JavaScript, y todas compartirán una sola hoja de estilos.

Resultado esperado

  • Una página de inicio (index.html) con un menú que abre cada ejercicio.
  • Cuatro ejercicios guiados: sumar, restar, multiplicar y dividir.
  • Un taller de cinco ejercicios con estructuras condicionales y validaciones, que resolverás tú.

Antes de empezar debes saber

  • Crear un formulario HTML con <label> e <input>.
  • Qué hacen addEventListener(), event.preventDefault() y Number() (guía anterior).

Cómo usar esta guía: Cada paso produce algo concreto. No pases al siguiente hasta que la prueba del paso funcione.

Carpeta o archivoContenido

js/Un archivo JavaScript por ejercicio.
ejercicios/Las páginas HTML de los cuatro ejercicios guiados.
taller/Las páginas HTML de los cinco ejercicios del taller.

¿Por qué separar?

  • HTML define la estructura, CSS la presentación y JavaScript el comportamiento. Separados son más fáciles de leer y de corregir.
  • Un archivo por ejercicio: cuando todo estaba en un solo <script>, un error en el ejemplo 1 detenía también los ejemplos 2, 3 y 4. Ahora un error solo afecta a su propia página.
  • Las variables de un archivo no chocan con las de otro, porque cada página carga solo su script.

Cómo crearla en VS Code

  1. En el Explorador, pasa el mouse sobre EVENTOS-JS y usa el ícono Nueva carpeta para crear css, js, ejercicios y taller.
  2. Con el ícono Nuevo archivo crea index.html en la raíz.
  3. Para crear un archivo dentro de una carpeta, haz clic en la carpeta y luego en Nuevo archivo. También puedes escribir la ruta completa, por ejemplo css/style.css.

Reglas para los nombres: Usa minúsculas, sin espacios, sin tildes y sin ñ: ejercicio1.html, no Ejercicio 1.html. Un nombre distinto en una sola letra rompe la ruta.

Opcional: crearla desde la terminal (Git Bash, macOS o Linux)

Ejecuta estos comandos dentro de la carpeta eventos-js. touch no existe en CMD ni en PowerShell de Windows; allí crea los archivos desde VS Code. Los archivos del taller los crearás en el paso 10.

Cómo probarlo

Compara tu Explorador con el árbol de arriba. Por ahora deben existir las carpetas, index.html, css/style.css y los archivos de los ejercicios 1 a 4.

Paso 4 de 16 · Guía

La hoja de estilos compartida

Escribe los estilos una sola vez. Todas las páginas los usarán enlazando este archivo.

Qué hace cada parte

  • box-sizing: border-box hace que el ancho de un elemento incluya su relleno y su borde. Así los inputs con width: 100% no se salen del formulario.
  • main limita el ancho del contenido a 560 px y lo centra con margin: 24px auto.
  • .botones input anula el ancho del 100 % solo para los botones.
  • Las clases .mensaje, .exito y .error se usarán en el taller. .mensaje:empty oculta el párrafo mientras no tenga texto.
Cómo probarlo

Todavía no se ve nada. Comprobarás este archivo en el paso 5, cuando una página lo enlace.

Paso 5 de 16 · Guía

La página de inicio

La página de inicio es el menú del proyecto. Desde ella se abren los nueve ejercicios.

Rutas relativas desde la raíz

index.html está en la raíz del proyecto, al mismo nivel que las carpetas. Por eso escribe la ruta entrando directamente en la carpeta:

  • href="css/style.css": entra a css y abre style.css.

Cómo probarlo

Clic derecho sobre index.html → Open with Live Server (o doble clic en el archivo desde la carpeta). Debes ver el encabezado azul oscuro y el texto con la fuente Arial. Si la página se ve en Times New Roman y sin colores, la ruta del CSS está mal escrita.

Los enlaces del taller mostrarán un error «no encontrado» hasta que crees esos archivos en el paso 10. Es normal.

Paso 6 de 16 · Guía

Ejercicio 1: la primera página con su script

Este ejercicio es el modelo que repetirás en todos los demás: una página HTML en ejercicios/ y su script en js/.

Rutas con ../

ejercicio1.html está dentro de la carpeta ejercicios. Para llegar a css o a js primero hay que salir de ella. ../ significa «sube una carpeta».

Ruta en ejercicio1.htmlRecorrido
../css/style.cssSale de ejercicios → entra a css → style.css
../js/ejercicio1.jsSale de ejercicios → entra a js → ejercicio1.js
../index.htmlSale de ejercicios → index.html en la raíz

¿Por qué el script va al final del <body>?

El navegador lee el HTML de arriba hacia abajo. Si el script se carga antes del formulario, getElementById("botonSumar") devuelve null porque el botón todavía no existe, y aparece el error Cannot read properties of null. Al final del <body>, todos los elementos ya están creados.

Cómo probarlo

Abre el inicio y entra al Ejercicio 1. Escribe 8 y 4: debe aparecer «Suma: 12». Deja un campo vacío: debe aparecer «Escribe los dos números.». Usa el enlace «Volver al inicio» para regresar.

Paso 9 de 16 · Guía

Herramientas para el taller

El taller usa algunas instrucciones nuevas. Léelas antes de empezar; cada ejercicio indica cuáles necesita.

1. Mostrar mensajes en la página en vez de alert()

textContent cambia el texto de un elemento. className cambia sus clases: exito y error ya están definidas en style.css.

2. if, else if y else

Las condiciones se revisan en orden y solo se ejecuta el primer bloque verdadero.

3. Operadores de comparación y lógicos

OperadorSignificaEjemplo
=== / !==igual / distinto (valor y tipo)clave !== confirmar
> < >= <=mayor, menor, mayor o igual, menor o igualedad >= 18
&&Y: las dos condiciones deben cumplirsea >= b && a >= c
||O: basta con que una se cumplanota < 0 || nota > 5
!NO: invierte la condición!correo.includes("@")
%residuo de una división10 % 2 da 0; 7 % 2 da 1

4. Validar números y texto

5. switch

switch compara una variable con varios valores exactos. Conviene cuando hay muchas opciones fijas, como las de un <select>. Sin break, la ejecución sigue con el siguiente case.

6. novalidate y return

  • En el taller los formularios llevan novalidate: el navegador no revisa los campos y tú haces todas las validaciones con if. Así practicas las condicionales.
  • Después de mostrar un error usa return; para detener la función. Así solo se muestra un mensaje a la vez y no se calcula con datos incorrectos.
