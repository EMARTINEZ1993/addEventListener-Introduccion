Paso 1 de 13

Paso 1 de 13 · Guía

Qué vamos a construir

Vas a organizar un proyecto web real a partir de los cuatro ejemplos de la guía de addEventListener(). En lugar de tener todo en un solo archivo, cada ejercicio tendrá su propia página HTML y su propio archivo JavaScript, y todas compartirán una sola hoja de estilos.

Resultado esperado

  • Una página de inicio (index.html) con un menú que abre cada ejercicio.
  • Cuatro ejercicios guiados: sumar, restar, multiplicar y dividir.
  • Un taller de cinco ejercicios con estructuras condicionales y validaciones, que resolverás tú.

Antes de empezar debes saber

  • Crear un formulario HTML con <label> e <input>.
  • Qué hacen addEventListener(), event.preventDefault() y Number() (guía anterior).

Cómo usar esta guía: Cada paso produce algo concreto. No pases al siguiente hasta que la prueba del paso funcione.

Carpeta o archivoContenido
index.htmlPágina de inicio con el menú. Está en la raíz del proyecto.
css/La hoja de estilos que comparten todas las páginas.
js/Un archivo JavaScript por ejercicio.
ejercicios/Las páginas HTML de los cuatro ejercicios guiados.
taller/Las páginas HTML de los cinco ejercicios del taller.

¿Por qué separar?

  • HTML define la estructura, CSS la presentación y JavaScript el comportamiento. Separados son más fáciles de leer y de corregir.
  • Un archivo por ejercicio: cuando todo estaba en un solo <script>, un error en el ejemplo 1 detenía también los ejemplos 2, 3 y 4. Ahora un error solo afecta a su propia página.
  • Las variables de un archivo no chocan con las de otro, porque cada página carga solo su script.

Cómo crearla en VS Code

  1. En el Explorador, pasa el mouse sobre EVENTOS-JS y usa el ícono Nueva carpeta para crear css, js, ejercicios y taller.
  2. Con el ícono Nuevo archivo crea index.html en la raíz.
  3. Para crear un archivo dentro de una carpeta, haz clic en la carpeta y luego en Nuevo archivo. También puedes escribir la ruta completa, por ejemplo css/style.css.

Reglas para los nombres: Usa minúsculas, sin espacios, sin tildes y sin ñ: ejercicio1.html, no Ejercicio 1.html. Un nombre distinto en una sola letra rompe la ruta.

Opcional: crearla desde la terminal (Git Bash, macOS o Linux)

Ejecuta estos comandos dentro de la carpeta eventos-js. touch no existe en CMD ni en PowerShell de Windows; allí crea los archivos desde VS Code. Los archivos del taller los crearás en el paso 8.

Cómo probarlo

Compara tu Explorador con el árbol de arriba. Por ahora deben existir las carpetas, index.html, css/style.css y los archivos de los ejercicios 1 a 4.

Paso 4 de 13 · Guía

La hoja de estilos compartida

Escribe los estilos una sola vez. Todas las páginas los usarán enlazando este archivo.

Qué hace cada parte

  • box-sizing: border-box hace que el ancho de un elemento incluya su relleno y su borde. Así los inputs con width: 100% no se salen del formulario.
  • main limita el ancho del contenido a 560 px y lo centra con margin: 24px auto.
  • .botones input anula el ancho del 100 % solo para los botones.
  • Las clases .mensaje, .exito y .error se usarán en el taller. .mensaje:empty oculta el párrafo mientras no tenga texto.
Cómo probarlo

Todavía no se ve nada. Comprobarás este archivo en el paso 5, cuando una página lo enlace.

Paso 5 de 13 · Guía

La página de inicio

La página de inicio es el menú del proyecto. Desde ella se abren los nueve ejercicios.

Rutas relativas desde la raíz

index.html está en la raíz del proyecto, al mismo nivel que las carpetas. Por eso escribe la ruta entrando directamente en la carpeta:

  • href="css/style.css": entra a css y abre style.css.
  • href="ejercicios/ejercicio1.html": entra a ejercicios y abre la página.
Cómo probarlo

Clic derecho sobre index.html → Open with Live Server (o doble clic en el archivo desde la carpeta). Debes ver el encabezado azul oscuro y el texto con la fuente Arial. Si la página se ve en Times New Roman y sin colores, la ruta del CSS está mal escrita.

Los enlaces del taller mostrarán un error «no encontrado» hasta que crees esos archivos en el paso 8. Es normal.

Paso 6 de 13 · Guía

Ejercicio 1: la primera página con su script

Este ejercicio es el modelo que repetirás en todos los demás: una página HTML en ejercicios/ y su script en js/.

Rutas con ../

ejercicio1.html está dentro de la carpeta ejercicios. Para llegar a css o a js primero hay que salir de ella. ../ significa «sube una carpeta».

Ruta en ejercicio1.htmlRecorrido
../css/style.cssSale de ejercicios → entra a css → style.css
../js/ejercicio1.jsSale de ejercicios → entra a js → ejercicio1.js
../index.htmlSale de ejercicios → index.html en la raíz

¿Por qué el script va al final del <body>?

El navegador lee el HTML de arriba hacia abajo. Si el script se carga antes del formulario, getElementById("botonSumar") devuelve null porque el botón todavía no existe, y aparece el error Cannot read properties of null. Al final del <body>, todos los elementos ya están creados.

Cómo probarlo

Abre el inicio y entra al Ejercicio 1. Escribe 8 y 4: debe aparecer «Suma: 12». Escribe 2.5 y 3.5: debe aparecer «Suma: 6» (los decimales también funcionan). Deja un campo vacío: debe aparecer «Escribe los dos números.». Usa el enlace «Volver al inicio» para regresar.

Taller 1: Par o impar

Desarrolla un programa que permita ingresar un número entero y mostrar si es par o impar.

Formulario

EtiquetaTipoid
Número enteronumbernumero

Formulario: formTaller1.

Instrucciones

  1. Utiliza addEventListener para escuchar el evento submit del formulario, empleando una función anónima.
  2. Valida que el campo no esté vacío. Si está vacío, muestra: Escribe un número.
  3. Verifica que el número ingresado sea entero. Si no lo es, muestra: Escribe un número entero.
  4. Si el número es válido, determina si es par o impar y muestra el resultado con la clase exito.

Taller 3: El mayor de tres números

Desarrolla un programa que permita ingresar tres números y mostrar cuál es el mayor, o avisar si los tres son iguales.

Formulario

EtiquetaTipoid
Número AnumbernumeroA
Número BnumbernumeroB
Número CnumbernumeroC

Formulario: formTaller3.

Instrucciones

  1. Utiliza addEventListener para escuchar el evento submit del formulario, empleando una función anónima. No uses Math.max(): el objetivo es practicar condicionales.
  2. Valida que ninguno de los tres campos esté vacío. Si alguno lo está, muestra: Completa los tres números.
  3. Si los tres números son válidos y son iguales entre sí, muestra: Los tres números son iguales.
  4. Si no son iguales, determina cuál es el mayor y muéstralo, por ejemplo: El número mayor es 9.

Taller 4: Formulario de registro

Desarrolla un programa que valide los datos de registro de un usuario y muestre el primer error que encuentre.

Formulario

EtiquetaTipoid
Nombretextnombre
Edadnumberedad
Correoemailcorreo
Contraseñapasswordclave
Confirmar contraseñapasswordconfirmar

Formulario: formTaller4.

Instrucciones

  1. Utiliza addEventListener para escuchar el evento submit del formulario, empleando una función con nombre llamada validarRegistro.
  2. Valida que el nombre no esté vacío (usa trim()). Si está vacío, muestra: Escribe tu nombre.
  3. Valida que la edad no esté vacía. Si está vacía, muestra: Escribe tu edad.
  4. Verifica que la edad sea un número entero entre 18 y 100. Si no lo es, muestra: La edad debe ser un número entero entre 18 y 100.
  5. Valida que el correo contenga @ y .. Si no, muestra: Escribe un correo válido.
  6. Verifica que la confirmación coincida con la contraseña. Si no coincide, muestra: Las contraseñas no coinciden.
  7. Si todos los datos son válidos, muestra «Registro exitoso. Bienvenido(a), Ana.» (usando el nombre escrito) con la clase exito.

Taller 5: Calculadora con selector

Desarrolla una calculadora que una los cuatro ejercicios guiados: el usuario escribe dos números y elige la operación en un selector.

Formulario

EtiquetaTipoid
Primer númeronumberprimero
Segundo númeronumbersegundo
Operaciónselectoperacion

Formulario: formTaller5.

Instrucciones

  1. Utiliza addEventListener para escuchar el evento submit del formulario, empleando una función con nombre llamada calcular. Usa switch para elegir la operación según el valor del selector.
  2. Valida que ninguno de los dos números esté vacío. Si alguno lo está, muestra: Escribe los dos números.
  3. Valida que se haya elegido una operación (el valor del selector no sea ""). Si no se eligió, muestra: Selecciona una operación.
  4. Si la operación es división, valida que el segundo número no sea cero. Si lo es, muestra: No es posible dividir entre cero.
  5. Si todo es válido, realiza la operación y muestra el resultado completo con la clase exito, por ejemplo: 8 × 2 = 16.
